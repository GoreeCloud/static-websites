GoreeCloud UI / GC UI · Isolated development candidate

One coherent experience.
Every system keeps its authority.

GoreeCloud UI is the shared design and interaction system for GoreeCloud-owned applications, websites, icons, and operating-system experiences. It is the fifth of the existing nine Integral Platform Systems and replaces the predecessor design authority.

Released, bounded scope

Foundations 1.0.1

A stable, Apache-2.0 licensed subset supporting semantic design tokens, a color engine and a browser theme controller. The original source stylesheet is pinned and checked for exact content identity in this preview.

01 / Language

Semantic tokens

Design roles for content, surfaces, emphasis, touch sizing, and focus instead of product-specific borrowed assets.

02 / Appearance

Adaptive color

Light, dark, and system choices retain legible surface contrast and usable controls. This preview tests its own implementation separately.

03 / Interaction

Accessible by design

Keyboard-visible focus, logical landmarks, responsive presentation, and reduced-motion behavior are independently verifiable obligations.

Release provenance: Foundations 1.0.1 source and archive. Not a claim of npm registry publication or a stable whole-library catalog.

Integral Platform System 5 of 9

Visual consistency without transferring authority.

GC UI provides presentation, accessibility and interaction consistency. Identity retains authentication, Privacy Shield owns privacy boundaries, Wardveil owns security enforcement, Everkeep owns recovery and Mesh owns connectivity. A consistent surface does not grant extra permissions.
