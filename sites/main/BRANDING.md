# GoreeCloud Website Branding

Branding authority: `GoreeCloud/branding-assets`.

The website must resolve GoreeCloud-controlled brand assets from the canonical branding repository and its `catalog.json`. Website-local public assets are synchronized publication derivatives only and must retain source provenance; they do not become independent branding authorities.

The current website-local `assets/goreecloud-logo.svg` matches the canonical `official/goreecloud-logo.svg` Git blob `082936062de7839148db89ea3ab4e86ff71341b0`.

Third-party artwork, when used in a reviewed historical or compatibility context, remains governed by its own source authority and licensing/trademark constraints rather than the GoreeCloud branding repository.

New or revised GoreeCloud logos, icons, artwork, wordmarks, social graphics, system identities, or product identities must be created and approved in `GoreeCloud/branding-assets` before synchronized website derivatives are updated.

Branding does not establish implementation, release, privacy, security, continuity, conformance, or production-readiness claims.
