GoreeCloud OS • Platform family

One operating-system family for different classes of device.

GoreeCloud OS brings a shared GoreeCloud identity to mobile devices, desktop PCs, televisions, virtualization hosts, and network-edge systems. Each variant keeps its own technical foundation and lifecycle, and this page separates verified current state from planned direction.

Shared identity, explicit boundaries

Common GoreeCloud principles without pretending every platform is the same.

Platform-appropriate foundations

Mobile and Desktop preserve their defined upstream operating-system families. TV, Hypervisor, and Router OS evolve against their own device, infrastructure, and networking requirements.

First-party integration over lock-in

GoreeCloud-specific applications, services, design, privacy, security, identity, continuity, and management can be integrated where the variant has verified support, without turning roadmap intent into a current capability claim.

Lifecycle truth stays visible

Development, planning, implementation evidence, release qualification, and production acceptance are separate states. Public wording follows the strongest current evidence available for each variant.
