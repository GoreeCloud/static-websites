GoreeCloud Office Suite

A first-party office family built around one shared engine.

Office is designed for local-first document creation, editing, calculation, presentation, structured data collection, recovery, interoperability, and later collaboration—without making core productivity depend on a remote service.

Current verified state: the primary GoreeCloud Office repository is in Development and contains the Rust workspace, Writer-oriented document-domain foundation, reversible command framework, package identity and validation semantics, governed schema/fixture test data, and CI. A usable Office application, Writer UI, persistence, rendering, export, collaboration, Glaze UI shell, and platform clients are not yet implemented.

Application family

One foundation, multiple focused editors.

Shared engine

Rust at the core

The accepted architecture uses a shared Rust Office Engine with platform-native presentation shells: Kotlin and Jetpack Compose on Android, TypeScript plus browser APIs with Rust/WASM on web, and Rust plus GTK 4 on Linux.

Native packages

Portable GoreeCloud formats

The planned package family includes .gcwriter, .gcsheet, .gcpresent, .gcform, and .gcdb. Native formats are intended to support GoreeCloud capabilities without trapping user data.

Interoperability

Open formats stay first-class

ODF 1.4 is the planned primary editable open-format family, with OOXML compatibility, structured data and web interchange, and PDF as a publication and print target.

Local first

Editing must work offline

Core file creation, editing, save, reopen, print, and export are intended to work without Internet access. Synchronization enhances the experience but is not backup.

Recovery

Designed for interruption

Atomic save, autosave, recovery journals, partial-recovery design, portability, and Everkeep continuity integration are planned core reliability boundaries.

Platform

Nine-system evaluation

Office must evaluate all nine Integral Platform Systems and implement every system applicable to each supported runtime. GoreeCloud Sync remains separately governed.
