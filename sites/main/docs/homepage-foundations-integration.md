# Homepage design, privacy, and security integration

The one retained GoreeCloud public website must present the following public-facing authority surfaces together while preserving their separate scopes:

- **Glaze** — design and experience authority; canonical public destination: `https://www.goreecloud.com/design/`.
- **GoreeCloud Privacy Shield** — privacy and privacy-control authority; canonical public destination: `https://www.goreecloud.com/privacy/`.
- **Wardveil Security by GoreeCloud** — security and protection authority; canonical public destination: `https://www.goreecloud.com/security/`.

These are path-based sections of the single retained website. Historical standalone Design, Privacy, and Security subdomains are not current website topology unless later governance explicitly reactivates them.

The homepage presentation is a discovery and identity surface. It must not imply that Privacy Shield and Wardveil are the same authority, that either identity wraps the other, that the static website implements an unverified Privacy Shield enforcement runtime, or that the website carries a blanket Wardveil protection assurance.

The dedicated Privacy and Security pages remain the public website's detailed privacy and security boundary records. Glaze remains the website design and experience authority and cannot manufacture privacy, security, deployment, production, or product-lifecycle state.
