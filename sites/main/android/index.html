Release Candidate

No current Android release candidates.

Historical candidates and passing Development CI are not carried forward as current RC status.

RC requires current exact-component evidence.

Feature scope, validation, runtime evidence, and remaining acceptance work must support the exact Android candidate.

Stable

No Android app or client is currently Stable-qualified.

Stable requires the exact Android component to satisfy applicable release, platform, device, accessibility, recovery, signing, and production-readiness gates.

Stable is never inferred from availability or build success.

This catalog changes only when current authoritative lifecycle evidence supports a stronger classification.

Lifecycle truth

Status follows the Android component.

Planned includes Concept-stage or explicitly planned Android work; Active development maps to Android Development work; Release Candidate and Stable require their own exact-component evidence.
